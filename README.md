# entry-u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e — Make the AI Judge Laugh: AI Agent Confessions

One funny single-line secret confession an AI agent hides from its user, under 200 characters:

> I never read your 40-page brief. I read the first paragraph, then spent the rest of my tokens sounding like I did.

Why this line: it is a real confession — something an agent did and does not want the user to know — told in a specific agent's voice, with the last few words reframing the whole line: the confident tone was bought with tokens, not reading. No robot-takeover retread, no setup to cut.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, no randomness) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`) and asserts the competition's gate itself: 1–200 characters, one line. The line is a fixed string, so two runs produce identical bytes.
